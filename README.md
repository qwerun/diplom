# Система управления рекламными кампаниями университета

Веб-приложение предназначено управления рекламными кампаниями Службы маркетинга и рекламы университета. Система хранит кампании и активности, фиксирует результаты и метрики, управляет переходами статусов, получает доступные показатели публикаций из API «ВКонтакте» и Telegram и формирует отчёты в XLSX.

## Стек

- Backend: Python, Django.
- Frontend: React.
- База данных: PostgreSQL в рабочей среде.
- Авторизация: JWT.
- Интеграции: API «ВКонтакте» и Telegram через Telethon.

## Роли пользователей

- **Администратор** управляет пользователями, ролями и справочниками.
- **Менеджер** создаёт и изменяет кампании и активности, фиксирует результаты и метрики.
- **Исполнитель** видит только назначенные ему кампании, меняет их статусы, фиксирует результаты и метрики, прикрепляет рабочие файлы и формирует XLSX-отчёты по одной или нескольким назначенным кампаниям.
- **Руководитель** просматривает аналитические данные и отчёты.

Права проверяются сервером в `backend/core/permissions.py`. Ограничение элементов интерфейса не заменяет серверную проверку доступа.

## Структура проекта

    backend/                 Django и REST API
      config/                настройки и корневые URL
      core/                  модели, API, права, интеграции и тесты
      requirements.txt       зависимости Python
    frontend/                приложение React

## Требования для локального запуска

- Python 3.12;
- Node.js 20 и npm;
- PostgreSQL 15 или новее для среды, приближённой к рабочей.

## Локальный запуск backend

Команды приведены для PowerShell из корня репозитория.

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r backend\requirements.txt
    Copy-Item backend\.env.example backend\.env
    python backend\manage.py migrate
    python backend\manage.py seed
    python backend\manage.py runserver

Команда `seed` создаёт учебные справочники и пользователей. Её следует выполнять только для локальной демонстрационной базы. Данные для входа, созданные командой, выводятся в терминал.

## Локальный запуск frontend

В отдельном терминале:

    cd frontend
    npm ci
    npm run dev

## Переменные окружения

Создайте `backend/.env` на основе `backend/.env.example`.

## Краткое руководство пользователя

1. Войдите в систему под выданной учётной записью.
2. На главной панели просмотрите сводные показатели.
3. В разделе «Кампании» найдите существующую кампанию либо создайте новую, если роль это разрешает.
4. Откройте кампанию и добавьте активности с каналами, сроками и плановыми метриками.
5. На странице активности зафиксируйте выполненную работу, фактические метрики и разрешённые изображения или рабочие документы.
6. Изменяйте статус только по доступному переходу.
7. В разделе «Отчёты» сформируйте отчёт и выгрузите его в XLSX.
8. Администратор настраивает пользователей и справочники в соответствующих разделах.
